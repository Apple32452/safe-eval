# Stage 13: smaller paired evaluations

This development study asks whether a smaller target-specific labeled subset
can certify the same direction as the complete fixed benchmark. It covers all
237 WMT23 system pairs and excludes both target systems from historical inputs.
The outcome is recorded binary error-free proportion, not official MQM or a
population significance ranking. Novelty is unresolved.

The [protocol](PROTOCOL.md) was committed before the complete run. The
[theory](THEORY.md) distinguishes per-pair error from simultaneous claims across
all pairs. Every paired query costs two target-system labels. Close pairs and
exact ties remain in the evaluation; unresolved does not mean equivalent.

From the repository root, after installing the existing requirements:

```bash
python -m unittest discover -s experiments/stage13 -p 'test_*.py' -v
OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1 python experiments/stage13/run_stage13.py --repeats 50 --workers 2 --output results/stage13_local
OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1 python experiments/stage13/audit_stage13.py --input results/stage13_local
python experiments/stage13/report_stage13.py --input results/stage13_local
```

Each output directory must be new. The complete run saves full ledgers, capital
curves and historical predictor audit states. The audit independently replays
the integer inference and first decisions, then creates compact `decisions.npz`.
The report requires the successful audit and writes per-pair, budget, stratified,
paired-control and family-error tables. No GPU or new annotations are required.

For a faster audit, replace the serial audit command with
`OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1 python experiments/stage13/audit_parallel_stage13.py --input results/stage13_local --workers 2`.
This utility executes the unchanged frozen auditor on disjoint case batches,
checks complete coverage, and restores the original case order. Its one-case
software check produces the same compact decision archive as the serial audit.
Use only one audit at a time for a given result directory.

`plot_stage13.py --input results/stage13_local` draws the primary budget curves
from those tables. It is a presentation addition outside the frozen inference.
If an archive is damaged, `recover_stage13.py --input results/stage13_local`
reruns only that exact case and accepts it only if its complete bytes reproduce
the original recorded SHA256. It preserves the original run metadata and saves
a recovery record. This does not permit replacing a scientific result with a
different outcome or parameter setting.

Small software check (not research evidence):

```bash
OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1 python experiments/stage13/run_stage13.py --repeats 2 --workers 1 --max-cases 1 --output results/stage13_smoke
OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1 python experiments/stage13/audit_stage13.py --input results/stage13_smoke
python experiments/stage13/report_stage13.py --input results/stage13_smoke
```

NumPy/BLAS differences may alter SVD signs or rounding-sensitive target
predictions. Arbitrary predictable predictions retain the integer conditional
budget; label-cost results can vary slightly across numerical implementations.
Only compact results are committed; full traces are generated by the commands.
