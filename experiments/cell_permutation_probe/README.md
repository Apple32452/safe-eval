# Cell permutation diagnostic

This folder preserves a failed, precommitted attempt to reduce reference-star
annotation cost by drawing individual system--item cells uniformly without
replacement and betting directly on their signed finite-population sum.

Read the [protocol](PROTOCOL.md) and the [negative result](FINDINGS.md).
`run_screen.py` generates fixed matrices and matched Stage 22 comparisons;
`analyze_screen.py` checks every saved row and the summary. The exact commands
are in the findings. The four tests check small-matrix completion, conditional
factor validity, the induced uniform pair path, and nonanticipation.

No WMT24 or WMT25 results were generated by this diagnostic. A valid method
with an unfavorable cost is not a publication-level novelty claim.
