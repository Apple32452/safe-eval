# Budgeted selective comparisons: closed development screen

Can individual reference-star scores be scheduled to **certify more strict
system comparisons at a fixed judgment budget**, while keeping the same
fixed-test-set and taskwise family error guarantee? This experiment tests a
paid-pilot estimate of each edge's remaining certificate footprint against
the frozen Stage 22 active-pruning policy and the Stage 14 evidence-first
cell scheduler.

Read the [precommitted protocol](PROTOCOL.md),
[findings and limitations](FINDINGS.md), and [saved results](results_reference/SUMMARY.json).
The 40-repeat synthetic gate **failed**: only the near-tie scenario met the
prespecified improvement over both controls. The candidate is a scheduling
heuristic using the existing inference rule. No ICML novelty claim follows.
WMT24 remains reserved; no additional WMT25 variant is justified by this
screen.
