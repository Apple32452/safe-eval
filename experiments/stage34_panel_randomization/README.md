This is a continuation of [Stage 33](../stage33/README.md). It provides
the six-allocation-per-document exact randomization test and an idealized
judgment-count calculation for the planned human feasibility study.

Read the [protocol](PROTOCOL.md), its [variance correction](AMENDMENT.md),
and the [research decision](FINDINGS.md). The saved
[planning calculation](results_reference/planning.json) is generated by
`power_plan.py`. The exact test accepts **completed** Stage 33 responses;
there are no human outcomes in this folder. No ICML novelty is claimed.
